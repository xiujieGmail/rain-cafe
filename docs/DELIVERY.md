## 功能交付范围

场景界面与移动端布局、四种交互状态、文字与实际麦克风多轮对话、语音和字幕、点击打断与迟到结果拦截、四种表情、望窗/举相机动作、环境变化、对话关联照片事件、48 帧序列动画、真实服务端模型链路、无密钥 Mock、错误提示与恢复已实现。人工与自动证据分开记录在 ACCEPTANCE.md。

题目允许选择一种多媒体，本项目选择序列帧动画；没有实现 ComfyUI、RAG、Agent、身份系统或后台，这些不作为已实现能力对外描述。真机手机和长期稳定性尚未专项验证。

## 评审运行

1. 克隆源码，在项目目录执行 ./start.sh，访问 http://localhost:3000。无需密钥即可演示文字与模拟输入、动画和故障降级。
2. 要验证真实语音，复制 .env.example 为 .env.local，按 README 的硅基流动配置填写评审自己的 Key，重启后在体验设置选择真实服务。只配置 STT 也可为 Mock 接入实际录音。
3. 从未提交用户 .env.local；它不属于交付材料。公开演示不携带本地密钥，访客可主动填写自己的密钥启用自定义服务。
4. 建议交付邮件附仓库、演示地址及最终录屏文件/链接，说明“在线默认演示/自带密钥真实体验 + 本地真实语音链路”。
