# 3–5 分钟录屏流程

本次代码和文档交付不包含录屏；请按以下顺序录制。本地运行真实服务，在线演示 https://xiujiegmail.github.io/rain-cafe/ 仅为 Mock。

1. 约 30 秒：展示雨夜咖啡馆、角色和输入区，说明 Next.js 全栈、序列帧动画及真实 STT → LLM → TTS。
2. 约 60–90 秒：实际麦克风问“你在等谁”，追问并展示倾听/思考/说话/待机与字幕。询问照片，展示媒体事件和情绪/动作；环境事件可在 Mock 用“雨停了，我们出去走走吧”确定触发。
3. 约 30–45 秒：在声音正在播放时开始新录音，明确录入旧声音停止，完成新一轮并验证旧字幕/照片未恢复。
4. 约 30–45 秒：切到明确标识的 Mock，在设置选择下一轮音频失败或模型超时，展示字幕降级或重试；恢复正常对话。说明故障是可重复的演示注入。
5. 剩余时间：展示手机尺寸布局和 README 启动命令、仓库链接、协议与已知限制。不要把尺寸模拟称为手机真机验收。

录制前试听确认系统声音可以被录入；避免画面中出现 .env.local、控制台密钥或其他私人窗口。实际连续演示与录屏覆盖情况以最终视频为准。
