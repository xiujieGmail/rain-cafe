# 交付演示流程

建议人工录制 3–5 分钟，说明当前运行的是静态演示还是本地完整后端。

1. 展示咖啡馆角色、四种交互状态与移动端布局。
2. 文字对话：你在等谁 → 我可以陪你 → 看看你的照片 → 你等的是谁 → 雨停了，我们出去走走吧。
3. 在角色说话时点击模拟语音输入，确认旧声音停止、字幕和照片清理，新轮继续。
4. 展示超时重试、音频失败字幕降级、照片失败继续对话和延迟旧回复被拦截。
5. 本地配置 STT 后，真实录音 → 上传识别 → 对话 → 播放；配置完整模型服务后再验收自由对话。Pages 无法完成此步骤。
6. 人工听音、实机录音和 3–5 分钟连续交流需另外验收，自动化不能代替。
